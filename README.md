# nocosheet

nocosheet is an open-source, fully no-code CMS and spreadsheet-style database. Model your data, manage records and publish content without writing code. It is self-hostable on Cloudflare and uses Cloudflare services for everything it needs.

## Features

- Fully no-code: create tables, fields and relations from the UI
- Spreadsheet-style grid for browsing and editing records
- Self-hostable on your own Cloudflare account
- Built on Cloudflare services (Workers, D1, R2 and more)
- Open source
